# WLAN aufwecken Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "WLAN aufwecken" action to the WLAN settings menu that toggles the WiFi radio off/on and reconnects to the saved network, recovering from the NetworkManager-powersave dropout without re-entering the WiFi password.

**Architecture:** One new `WifiWorker.start_wake()` background-thread method (same class/pattern as the existing `start_scan`/`start_connect`/`start_device_action`), two new `UIState` fields for status feedback, one new menu item, and a status-branch at the top of `render_wifi_menu` mirroring `render_wifi_device`'s existing "working"/"error" pattern.

**Tech Stack:** Python 3, existing `connectivity.py` (`wifi_set_enabled`, `wifi_connect_known`), existing `threading`-based worker pattern in `main.py`.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-09-16-wifi-wake-design.md`.
- The action MUST run in a background thread, never inline in the render loop - `connectivity.wifi_connect_known()` can block up to 20s (its own documented timeout), and this codebase has a documented history of exactly this freeze class (see `SyncWorker`/`StatusWorker` docstrings in `main.py`).
- No multi-network selection - reconnect to the first entry in `state.wifi_known_networks` (this device has exactly one saved WiFi network in practice; see spec's YAGNI note).
- No new pip dependencies, no new sudoers rules - `wifi_set_enabled`/`wifi_connect_known` already exist and are already covered by the `mp3player-network` sudoers rule set up earlier this session.

- [ ] **Step 4: Add `WifiWorker.start_wake` and wire it into `handle_event`**

In `Software/main.py`, inside `class WifiWorker:`, add (matching the exact shape of `start_scan`/`_scan` right above it):

```python
    def start_wake(self):
        if self._thread and self._thread.is_alive():
            return
        self._thread = threading.Thread(target=self._wake, daemon=True)
        self._thread.start()

    def _wake(self):
        connectivity.wifi_set_enabled(False)
        connectivity.wifi_set_enabled(True)
        known = self.state.wifi_known_networks
        if known:
            success, error = connectivity.wifi_connect_known(known[0]["name"])
        else:
            success, error = True, None
        self.state.wifi_wake_done(success, error)
```
